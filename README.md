# Интернет-магазин «Web-Larёk»
«Web-Larёk» — это интернет-магазин с товарами для веб-разработчиков, где пользователи могут просматривать товары, добавлять их в корзину и оформлять заказы. Сайт предоставляет удобный интерфейс с модальными окнами для просмотра деталей товаров, управления корзиной и выбора способа оплаты, обеспечивая полный цикл покупки с отправкой заказов на сервер.

## Архитектура приложения

Код приложения разделен на слои согласно парадигме MVP (Model-View-Presenter), которая обеспечивает четкое разделение ответственности между классами слоев Model и View. Каждый слой несет свой смысл и ответственность:

Model - слой данных, отвечает за хранение и изменение данных.  
View - слой представления, отвечает за отображение данных на странице.  
Presenter - презентер содержит основную логику приложения и  отвечает за связь представления и данных.

Взаимодействие между классами обеспечивается использованием событийно-ориентированного подхода. Модели и Представления генерируют события при изменении данных или взаимодействии пользователя с приложением, а Презентер обрабатывает эти события используя методы как Моделей, так и Представлений.

### Базовый код

#### Класс Component
Является базовым классом для всех компонентов интерфейса.
Класс является дженериком и принимает в переменной `T` тип данных, которые могут быть переданы в метод `render` для отображения.

Конструктор:  
`constructor(container: HTMLElement)` - принимает ссылку на DOM элемент за отображение, которого он отвечает.

Поля класса:  
`container: HTMLElement` - поле для хранения корневого DOM элемента компонента.

Методы класса:  
`render(data?: Partial<T>): HTMLElement` - Главный метод класса. Он принимает данные, которые необходимо отобразить в интерфейсе, записывает эти данные в поля класса и возвращает ссылку на DOM-элемент. Предполагается, что в классах, которые будут наследоваться от `Component` будут реализованы сеттеры для полей с данными, которые будут вызываться в момент вызова `render` и записывать данные в необходимые DOM элементы.  
`setImage(element: HTMLImageElement, src: string, alt?: string): void` - утилитарный метод для модификации DOM-элементов `<img>`


#### Класс Api
Содержит в себе базовую логику отправки запросов.

Конструктор:  
`constructor(baseUrl: string, options: RequestInit = {})` - В конструктор передается базовый адрес сервера и опциональный объект с заголовками запросов.

Поля класса:  
`baseUrl: string` - базовый адрес сервера  
`options: RequestInit` - объект с заголовками, которые будут использованы для запросов.

Методы:  
`get(uri: string): Promise<object>` - выполняет GET запрос на переданный в параметрах ендпоинт и возвращает промис с объектом, которым ответил сервер  
`post(uri: string, data: object, method: ApiPostMethods = 'POST'): Promise<object>` - принимает объект с данными, которые будут переданы в JSON в теле запроса, и отправляет эти данные на ендпоинт переданный как параметр при вызове метода. По умолчанию выполняется `POST` запрос, но метод запроса может быть переопределен заданием третьего параметра при вызове.  
`handleResponse(response: Response): Promise<object>` - защищенный метод проверяющий ответ сервера на корректность и возвращающий объект с данными полученный от сервера или отклоненный промис, в случае некорректных данных.

#### Класс EventEmitter
Брокер событий реализует паттерн "Наблюдатель", позволяющий отправлять события и подписываться на события, происходящие в системе. Класс используется для связи слоя данных и представления.

Конструктор класса не принимает параметров.

Поля класса:  
`_events: Map<string | RegExp, Set<Function>>)` -  хранит коллекцию подписок на события. Ключи коллекции - названия событий или регулярное выражение, значения - коллекция функций обработчиков, которые будут вызваны при срабатывании события.

Методы класса:  
`on<T extends object>(event: EventName, callback: (data: T) => void): void` - подписка на событие, принимает название события и функцию обработчик.  
`emit<T extends object>(event: string, data?: T): void` - инициализация события. При вызове события в метод передается название события и объект с данными, который будет использован как аргумент для вызова обработчика.  
`trigger<T extends object>(event: string, context?: Partial<T>): (data: T) => void` - возвращает функцию, при вызове которой инициализируется требуемое в параметрах событие с передачей в него данных из второго параметра.

## Данные

### Интерфейс `IProduct`
Данный интерфейс описывает товар интернет-магазина.

Поля:

```ts
id: string;
description: string;
image: string;
title: string;
category: string;
price: number | null;
```

- `id` - уникальный идентификатор товара.
- `description` - описание товара.
- `image` - путь к файлу изображения товара.
- `title` - название товара.
- `category` - категория товара.
- `price` - стоимость товара. Если значение равно `null` - товар недоступен для покупки.

### Тип `TPayment`
Тип, описывающий доступные способы оплаты.

```ts
type TPayment = 'card' | 'cash';
```

- `card` - оплата банковской картой.
- `cash` - оплата наличными.

### Интерфейс `IBuyer`
Интерфейс, описывающий данные покупателя.

```ts
payment: TPayment | null;
email: string;
phone: string;
address: string;
```

- `payment` - выбранный способ оплаты.
- `email` - адрес электронной почты.
- `phone` - номер телефона.
- `address` - адрес доставки.

## Модели данных

### Класс `Products`
Данный класс отвечает за хранение каталога товаров.

### Конструктор

```ts
constructor()
```

Конструктор не принимает параметров.

#### Поля

`items: IProduct[]`
Хранит массив каталога товаров.

`preview: IProduct | null`
Хранит товар, выбранный для отображения в модальном окне.

#### Методы

`setItems(items: IProduct[]): void`
Сохраняет массив товаров

`getItems(): IProduct[]`
Возвращает массив товаров.

`getItem(id: string): IProduct | undefined`
Возвращает товар по его идентификатору.

`setPreview(product: IProduct): void`
Сохраняет выбранный товар.

`getPreview(): IProduct | null`
Возвращает выбранный товар.

### Класс `Basket`
Данный класс отвечает за хранение товаров, которые пользователь добавил в корзину.

#### Конструктор

```ts
constructor(events: EventEmitter)
```
Принимает брокер событий EventEmitter, который используется для генерации события `basket:changed` при изменении содержимого корзины.


#### Поля

`items: IProduct[]`
Массив товаров, добавленных в корзину.

#### Методы

`getItems(): IProduct[]`
Возвращает список товаров.

`add(product: IProduct): void`
Добавляет товар в корзину.

`remove(product: IProduct): void`
Удаляет товар из корзины.

`clear(): void`
Полностью очищает корзину.

`getTotal(): number`
Возвращает общую стоимость товаров.

`getCount(): number`
Возвращает количество товаров.

`hasProduct(id: string): boolean`
Проверяет наличие товара в корзине по его идентификатору.

### Класс `Buyer`
Данный класс отвечает за хранение данных покупателя.

#### Конструктор

```ts
constructor(events: EventEmitter)
```
Принимает брокер событий EventEmitter, используемый для генерации события `buyer:changed` при изменении данных покупателя.



#### Поля
`data: IBuyer`
Хранит данные покупателя, включая способ оплаты, адрес, телефон и email.
До заполнения формы способ оплаты имеет значение `null`, а остальные поля представлены пустыми строками.

#### Методы

`setData(data: Partial<IBuyer>): void`
Сохраняет данные покупателя. Позволяет изменять отдельные поля без потери уже сохраненных данных.

`getData(): IBuyer`
Возвращает данные покупателя.

`clear(): void`
Очищает данные покупателя.

`validate(): TBuyerErrors`
Проверяет заполнение данных покупателя и возвращает объект с сообщениями об ошибках.

## Слой коммуникации

### Класс `WebLarekApi`

Данный класс отвечает за взаимодействие приложения с сервером. Используется экземпляр класса `Api` для выполнения HTTP-запросов.

#### Конструктор

```ts
constructor(api: IApi)
```
Принимает объект, реализующий интерфейс `IApi`, через который выполняются запросы к серверу.

#### Поля
`api: IApi`
Хранит экземляр класса API, используемый для выполнения запросов к серверу.

#### Методы

`getProducts(): Promise<IProductList>`
Выполняет GET-запрос на эндпоинт `/product/` и возвращает объект со списком товаров.

`orderProducts(order: IOrder): Promise<IOrderResult>`
Выполняет POST-запрос на эндпоинт `/order/`, отправляет данные заказа и возвращает результат оформления заказа.

## Слой представления (View)
Слой представления отвечает за отображение данных приложения и взаимодействие с пользователем. Каждый класс представления отвечает за свой блок разметки.

### Абстрактный класс Card
Базовый класс для карточек товара. Содержит общий для всех карточек функционал отображения названия и цены товара. От него наследуются классы `CardCatalog`, `CardPreview` и `CardBasket`.

#### Конструктор
```ts
constructor(container: HTMLElement)
```

Принимает DOM-element, где отображается карточка.

#### Поля

`titleElement: HTMLElement`
Элемент для отображения названия товара.
`priceElement: HTMLElement`
Элемент для отображения цены товара.

#### Сеттеры
`title` - устанавливает название товара.
`price` - устанавливает цену товара. Если цена равна `null` - отображается текст "Бесценно".

### Класс CardCatalog
Отвечает за отображение карточки товара в каталоге. Наследуется от класса Card.
Дополнительно отображает категорию товара и изображение.

#### Поля

`categoryElement: HTMLElement`
Элемент для отображения категории товара.

`imageElement: HTMLImageElement`
Изображение товара.

#### События
`card:select` - генерируется при нажатии на карточку товара. Используется для выбора товара и открытия его подробного представления.

### Класс CardPreview
Отвечает за отображение выбранного товара в модальном окне. Наследуется от класса Card.
Отображает категорию, изображение, название, описание и цену товара, а также кнопку добавления товара в корзину.

#### Поля

`categoryElement: HTMLElement`
Элемент для отображения категории товара.

`imageElement: HTMLImageElement`
Изображение товара.

`descriptionElement: HTMLElement`
Элемент для отображения описания товара.

`buttonElement: HTMLButtonElement`
Кнопка добавления товара в корзину.

#### События 
`card:action` - генерируется при нажатии на кнопку действия с товаром.
Используется презентером для выполнения действия с выбранным товаром: добавления товара в корзину или удаления его из корзины в зависимости от текущего состояния корзины.

### Класс CardBasket
Отвечает за отображение товара в корзине. Наследуется от класса Card.
Отображает порядковый номер товара и кнопку удаления товара из корзины.

#### Поля

`indexElement: HTMLElement`
Элемент для отображения порядкового номера товара.

`buttonElement: HTMLButtonElement`
Кнопка удаления товара из корзины.

#### События 
`basket:remove` - генерируется при нажатии на кнопку удаления товара и передает id удаляемого товара.

### Класс Form
Базовый класс для форм. Содержит общий для форм функционал работы с полями, кнопкой отправки и отображением ошибок.

#### Конструктор

```ts

```
Принимает DOM-элемент формы.

#### Поля

`submitButton: HTMLButtonElement`
Кнопка отправки формы.

`errors: HTMLElement`
Элемент для отображения ошибок валидации.

#### Сеттеры
`valid` - устанавливает доступность кнопки отправки формы.

`errorsText` - Отображает сообщение об ошибке.

#### События
`form:input` - генерируется при изменении значения поля формы. Передает название поля и его значение.

```ts

}
```

#### Поля

`paymentButtons: HTMLButtonElement[]`

#### События

### Класс ContactsForm
Отвечает за форму ввода контактных данных покупателя. Наследуется от класса Form.

#### Поля

`emailInput: HTMLInputElement`
Поле ввода электронной почты.

`phoneInput: HTMLInputElement`
Поле ввода номера телефона.

#### События 

`contacts:email` - генерируется при изменении поля email.
Передает введенный адрес электронной почты:

```ts
{
  email: string;
}
```

`contacts:phone` - генерируется при изменении поля телефона.
Передает введенный номер телефона:

```ts 
{
  phone: string;
}
```

`contentElement` - устанавливает содержимое модального окна.

#### События 
При закрытии модального окна генерирует событие закрытия.

### Класс BasketView
Отвечает за отображение содержимого корзины.

#### Поля

`list: HTMLElement`
Список товаров в корзине.

`price: HTMLElement`

#### События

### Класс Success

#### Поля 

`totalElement: HTMLElement`
Элемент для отображения суммы списанных синапсов.

`total` - отображает сумму списанных синапсов.

#### События
При нажатии на кнопку генерирует событие `success:close`, используемое для закрытия сообщения об успешном оформлении заказа и возврата к каталогу.

## События приложения
События используются для связи компонентов представления с Презентером.
При действиях пользователя компоненты View генерируют события через брокер `EventEmitter`.

### События карточек

#### `card: select`
Генерируется классом `CardCatalog` при нажатии на карточку товара.
Используется для выбора товара и открытия его подробного представления.

#### `card:action`
Генерируется классом `CardPreview` при нажатии на кнопку "В корзину".
Используется для добавления выбранного товара в корзину или удаления товара из корзины в зависимости от текущего состояния корзины.

#### `basket:remove`
Генерируется классом `CardBasket` при нажатии на кнопку удаления товара.
Используется для удаления товара из корзины.

### События форм
События форм используются для передачи данных из компонентов представления в презентер.

`order:payment` - выбор способа оплаты.
`order:address` - изменение адреса доставки.
`contacts:email` - изменение email.
`contacts:phone` - изменение телефона.
`contacts:submit` - отправка контактной формы.
`form:submit` - генерируется при отправке формы.

### События корзины

#### `basket:order`
Генерируется классом BasketView при нажатии на кнопку "Оформить".
Используется для перехода к форме оформления заказа.

#### `basket:changed`
Генерируется классом Basket при добавлении, удалении или полной очистке товаров. Используется для обновления отображения корзины и ее общей стоимости.

### События модального окна

#### `modal:close`
Генерируется классом Modal при нажатии на кнопку закрытия модального окна.
Используется для закрытия модального окна.

### События успешного оформления заказа

#### `success:close`
Генерируется классом Success при нажатии на кнопку "За новыми покупками!".
Используется для закрытия сообщения об успешном оформлении заказа и возврата к каталогу.
